# WebDAV 同步

在「设置 → WebDAV 同步」填写 HTTPS WebDAV 地址、账号、应用密码和同步文件夹。默认文件夹仍为 `MiriaGoSync`，可直接连接旧版 MiriaGo WebSync 的云端数据。密码可选择保存在应用或系统凭据存储中。

## 选择同步方向

点击“保存并刷新版本”查看本地和云端的最后更新时间、计划数与记录数。每次点击“选择同步方向”都会重新读取两端版本，再选择：

- **本地 → 云端**：保留本地，完整覆盖云端计划和记录；云端独有项目会被移除。
- **云端 → 本地**：保留云端，完整覆盖本地计划和记录；本地独有项目会被移除。云端为空时不可选。

本地和云端时间均以设备时区显示。旧本地数据可能只能通过记录中的内容时间估算；旧云端清单若没有更新时间，会显示“旧版本未记录”。预览缓存和界面状态不会更新用户数据时间。

## 同步历史与错误反馈

每次同步在本机记录开始时间、完成时间、方向、完成/失败/取消状态及简要图片数量，按 WebDAV 账号分别保存，最多保留 30 条。取消选择也会留下取消记录。同步历史不上传至 WebDAV。

失败信息会显示停止阶段、具体原因、下一步处理建议、数据是否已写入任一侧及错误代码，并可复制。认证、权限、网络超时、证书、磁盘空间、文件缺失、云端清单损坏和版本竞争会给出对应处理建议。若云端已写入而本地保存失败，界面会明确说明部分完成；请刷新两端版本后再决定方向。

## 图片与重复传输

同步图片按原始字节和 SHA-256 内容哈希保存到 `objects/<SHA-256>`。上传前先检查对象是否存在，下载后校验哈希。参考图缓存的本地哈希文件名不会被误判为远端 URL，因此不会仅因本地缓存路径变化而反复下载；内容相同的对象也不会重复上传。

Android 文件 URI 会按原始字节读取。GIF、HEIF/HEIC、AVIF 等图片不经过仅支持 JPEG/PNG/WebP 的导出校验；能否显示取决于设备解码能力。下载方向可以用完整云端图片修复本地缺失的同步图片。缺少拍摄照片或调色图时会说明记录、字段和文件路径，不会静默丢弃。

## 数据保护与云端格式

- 写入前检查同步清单、关联关系和图片哈希，并确认本地记录在同步期间没有变化。
- 更改本地记录前保存本机快照备份；覆盖云端清单前保存旧清单到云端 `history/<旧清单SHA-256>.json`，并保存云端清单的本地副本。
- 云端清单采用 ETag 条件写入。另一设备在同步期间修改云端数据时，本次操作会停止，要求刷新后重新选择方向。
- 图片对象不会自动清理，旧历史清单仍可引用。

云端文件格式保持 MiriaGo 兼容：`<同步文件夹>/manifest-v1.json`、`objects/<SHA-256>` 和 `history/<SHA-256>.json`；清单的格式 ID 为 `miriago-webdav`，版本为 1。单张图片上限 128 MiB，清单上限 32 MiB。
